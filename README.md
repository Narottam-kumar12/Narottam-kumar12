### 🧠 Twitter Sentiment Analysis — Research + Production System
> Published research paper · 88.79% train accuracy · 77.70% test accuracy

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![LightGBM](https://img.shields.io/badge/LightGBM-00BCD4?style=flat-square)
![XGBoost](https://img.shields.io/badge/XGBoost-FF6600?style=flat-square)
![SMOTE](https://img.shields.io/badge/SMOTE-Imbalanced_Learn-85C1E9?style=flat-square)
![TF-IDF](https://img.shields.io/badge/TF--IDF-scikit--learn-F7931E?style=flat-square)

- 4-model soft-voting ensemble: LightGBM + XGBoost + Random Forest + Logistic Regression
- Multi-class SMOTE applied on training set only — zero data leakage
- TF-IDF with bi-gram support · 5,000 features · stratified 80/20 split
- Negative class F1: **0.85** · Neutral: **0.63** · Positive: **0.69**
- Supervised by Dr. Vimal Kumar, Assistant Professor, CSED, MMMUT

🔗 [View Repository →](https://github.com/Narottamkumar12/NLPTask)
